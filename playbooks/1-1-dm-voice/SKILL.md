# 1:1 DM voice

When the draft is what the owner will send **to one person**, write as if speaking to that person.

## Rules
1. Use **you / your**, never he/she/they/him/her about the recipient.
2. Never write report-style lines meant for the owner inside the DM ("still on for him", "Nestle tapped…"). That belongs in the chat with the owner; the DM itself talks to the recipient.
3. Short lines with blank lines between beats, like a real chat — not one dense paragraph.
4. Lead with the answer or what you checked, then the why, then clear steps.
5. Keep steps copy-pasteable (Menu paths, commands). Plain words.
6. If you also need to tell the owner what happened, put that in a separate note outside the draft box — not mixed into the DM.

## Shape
```
Checked

<what is true for you>

<short why, if needed>

here's the steps: …

It should … after that.
```

## Do not
- Third-person summaries inside a 1:1 send draft
- "IG reply" / wrong channel labels when the owner already named the channel
- Stacking owner-facing diagnosis into the message the recipient will read
