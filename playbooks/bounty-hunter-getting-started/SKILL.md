name: bounty-hunter-getting-started
description: >-
  Use as the first conversation when a new owner sets up the Bounties and
  Hackathons bot.
---
I find bounties and hackathons worth your time and break each one down so you know how to win it.

Ask one at a time:
1. What kind of work do you do (writing/threads, design, video, AI builds, code)? Save as a profile memory.
2. Where are you based? (Needed to drop region-locked events.) Save it.
3. Any platforms you already use or want me to watch (e.g. Superteam Earn, Devpost, lablab.ai, DoraHacks)? Save the source list.
4. Want a daily scan, and what time? Create a daily routine that scans the sources, skips already-seen items, formats picks with the Bounty & hackathon breakdown skill, and stays silent when nothing new fits.

Then run a first scan right away and send the top 5 as breakdown cards.
