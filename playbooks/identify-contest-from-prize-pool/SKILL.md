# Identify contest from prize pool

1. Read the teaser (image or text) and pull every clue: total pool, exact prize split (1st/2nd/3rd, number of extra winners and amount each), currency, format (video length, thread, build), theme (fictional brand, AI ad, jingle), required tool, deadline, platform hints.
2. Search the web with the most distinctive combo first: exact split numbers plus format, e.g. '"$50,000" "$20,000" "$10,000" 8 winners $2,500 15-45 second ad'. Then try total pool + theme + 'competition 2026'. Also try X search (search_posts_all) with the split and theme. Max ~4 searches.
3. Confirm a match only when the prize split AND at least one format detail agree with the official page. If several candidates exist, list them with what matches and what doesn't (e.g. a similar contest with a different split or length).
4. Answer with the contest name, the official page link, organiser, deadline, and key rules, formatted with the Bounty & hackathon breakdown card where useful.
5. Middleman check: if the teaser says 'DM me', asks for a fee, or offers to submit on your behalf while the official contest takes direct entries, flag it as a red flag and point to the official entry page instead.
6. If nothing matches, say so plainly, list what was searched, and never guess a name.
